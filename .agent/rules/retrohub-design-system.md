# Reglas Inquebrantables de Diseño e Identidad Visual de RetroHub

1. **PROHIBICIÓN ABSOLUTA DE EMOJIS (`NADA DE EMOJIS`)**:
   - Queda terminantemente prohibido usar emojis Unicode (ej. 🎮, 🕹️, 🤝, 🏆, ✨, 💬, 👤, 🌐, etc.) en cualquier interfaz, botón, etiqueta, notificación, título honorífico o estado vacío del proyecto.
   - **Todo icono debe ser un SVG vectorial colorido o de librería** (Lucide / Phosphor / Iconos vectoriales duotono o con gradientes y contenedores cromáticos) siguiendo la estética limpia y táctil de `index.html`.

2. **Consistencia Visual con `index.html`**:
   - Todas las páginas (`profile.html`, `index.html`, `iisu_network.html`, etc.) deben compartir la estética limpia de `index.html`: botones circulares táctiles con iconos SVG coloridos (Teal `#00d2be`, Naranja `#ff7300`, Azul Cielo `#0284c7`, Rojo Escarlata `#e60012`, Esmeralda `#10b981`, Ámbar `#f59e0b`, Violeta `#8b5cf6`), cristal porcelana limpio (`#ffffff` / `rgba(255,255,255,0.92)`), tipografía `Space Grotesk` + `Outfit`, y riel/barra superior coherente.

3. **Barra Superior Común y Chat Lateral**:
   - Toda la web comparte la barra superior con el **logo de RetroHub a la izquierda** y el **perfil de usuario + acceso al Chat Lateral a la derecha**.
   - El sistema de **Chat Lateral** permite enviar mensajes directos a amigos, crear grupos de chat y que **cualquier miembro pueda invitar** a otros usuarios al grupo.
